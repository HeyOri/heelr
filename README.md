# Heelr website

Static marketing site for Heelr: aerial cattle counting for feedlots.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `favicon.svg` — hoofprint icon

## Hosting
Served by GitHub Pages from the `main` branch root. Custom domain: add a `CNAME` file containing `heelr.ai` once the domain is bought.

## Contact form
Submissions go to [Web3Forms](https://web3forms.com), which emails them on. Set `WEB3FORMS_KEY` in `index.html` to the access key Web3Forms emails you.
